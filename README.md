# NCI Dose Tools

> **Documentation has moved.** All NCI Dose Tools user manuals, API manuals, and version histories previously maintained in this repository and its Wiki are now available from the [NCI Dose Tools Information Portal](https://ncidose.github.io/).

For approved software downloads, account management, and submitting technical questions, visit the [NCI Dose Tools User Portal](https://portal.ncidosetools.com/). Published answers can be searched without an account in the public [NCI Dose Tools Q&A](https://ncidose.github.io/#/questions).

The [official NCI radiation dosimetry tools page](https://dceg.cancer.gov/tools/radiation-dosimetry-tools) remains the authoritative institutional source for access and licensing information.
